# Вход со второй попытки: границы исправления

Пользователь подтвердил две последовательные попытки: первая показала отсутствие ответа,
вторая завершилась входом. Код ошибки и длительность первой попытки не сохранены;
конкретный сетевой сбой этого случая не установлен. На старых native-сборках кнопка
входа могла сначала обновлять сохранённую сессию, а не проверять пароль заново.

Исправлена отдельно воспроизводимая регрессия отката: после уже успешной авторизации
временный сбой загрузки профиля/серверов больше не возвращает пользователя к форме входа.
Принятый аккаунт сохраняется; повторяется только GET через 1/3/10 секунд. После этого
новый bootstrap-loop останавливается (обычный прежний Home polling остаётся). Явные
401/403 закрывают сессию. Автоматические повторы POST с паролем не добавлены.

Поздние ответы/ошибки, таймеры и завершение старого logout отгорожены от нового аккаунта.
Повторные нажатия до React rerender больше не запускают параллельную отправку формы;
пользовательская смена экрана не снимает lock незавершённого запроса.

Добавлена диагностика фиксированных этапов login/session/profile: длительность, HTTP
статус и категория ошибки. До успешного входа она хранится только в памяти до пяти минут;
первая неудачная попытка может попасть в админку после успешного повтора того же логина.
Пароли, токены, тексты ошибок, тела запросов, URL и логины в payload не попадают. При смене
аккаунта отправитель отключается; готовая очищенная очередь разделена по владельцам.
Неуспешный вход с последующим закрытием приложения до подтверждения аккаунта не загружается.
У старого установленного клиента этой новой диагностики нет.

Проверки: 35 тестов actual API/bootstrap/Auth handlers, auth diagnostics/privacy suite,
21 server diagnostics test, полный web build с TypeScript — PASS. Тесты включают timeout,
ручной повтор, 401/403, logout и смену пользователя в полёте, секреты в ошибках и отсутствие
анонимной отправки. Существующие updater и transport suites также прошли.

Диагностическая схема дополнительно различает direct/webaudio захват микрофона для
следующего отдельного iOS-исправления. Это поле само не изменяет аудиоповедение.
